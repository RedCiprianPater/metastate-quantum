#
# app.py lazy-imports qiskit_ibm_runtime inside ibm_service() and gates the
# IBM backend behind HAVE_IBM, so the worker starts and Osaka + Origin +
# simulator all work without it. Once the buildCommand is updated per
# SETUP.md, add `qiskit-ibm-runtime==0.30.0` back below the qiskit pin.
#
# Origin's pyqpanda3 (China · Wukong 72q) is intentionally NOT listed:
# it's installed opportunistically via render.yaml's buildCommand fallback
# because the wheel is not always available for every glibc / Python combo.
# The worker probes it at runtime and downgrades to sim if missing.
