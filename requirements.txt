#                  /chainstate/route (internal · dual-secret gate)

#   2. v0.7.8  Hyperspectral Sensory Synthesis (Paper VIII)
#      Endpoints:  /perception/hyperspectral · /perception/texture

#   3. v0.7.9  Cyberspace Census (Paper IX)                        ← NEW
#      Endpoints:  /census/status   (public)
#                  /census/daily    (internal · CHAINSTATE_INTERNAL_TOKEN)
#                  /census/trigger  (internal · CHAINSTATE_INTERNAL_TOKEN)
#      Cron:       05:00 UTC daily (APScheduler)
#
# All three responsibilities coexist in one FastAPI app: quantum routes,
# perception routes, and census subsystem are independent; failure of one
# does NOT affect the others. Perception + census endpoints degrade
# gracefully when their optional deps are missing (try/except HAVE_* pattern
# in perception.py and app.py).
#
# ═══════════════════════════════════════════════════════════════════════════
# Build & runtime notes for Render:
#
# buildCommand (from render.yaml, keep unchanged from v0.7.7):
#   pip install --upgrade pip
#   pip install 'setuptools>=65,<70' wheel
#   pip install --prefer-binary --no-build-isolation -r requirements.txt
#   (pip install --prefer-binary --no-build-isolation pyqpanda3 || echo
#      'pyqpanda3 unavailable on this platform; Origin backend will report
#       unavailable and fall back to simulator/other backends')
#
# The pyqpanda3 install is deliberately OUTSIDE this file --- the Origin
# Wukong SDK is not always available on Render Python 3.11 build platform,
# so the buildCommand attempts it with a fallback. Keeping it out of
# requirements.txt lets the entire build succeed when it isn't available.
#
# startCommand:
#   uvicorn app:app --host 0.0.0.0 --port $PORT
# ═══════════════════════════════════════════════════════════════════════════
